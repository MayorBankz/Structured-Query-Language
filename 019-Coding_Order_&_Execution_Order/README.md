# SQL - CODING ORDER & EXECUTION ORDER
## TOOL - MySQL
## DATE - 27-01-2026

---
### CODING ORDER

```sql
SELECT DISTINCT TOP 2
    COL 1
    SUM(COL2)
FROM Table
WHERE COL = 10
GROUP BY COL 1
HAVING SUM(COL 2) > 30
ORDER BY COL 1 ASC
```
---sql
### EXECUTION ORDER 
1. `FROM`
2. `WHERE`
3. `GROUP BY`
4. `HAVING`
5. `SELECT DISTINCT`
6. `ORDER BY`
7. `TOP 2`
